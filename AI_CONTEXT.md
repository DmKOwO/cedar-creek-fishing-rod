# Cedar Creek Fishing Rod — AI Context & Architecture Guide

> Этот документ создан специально для нейросетевых ассистентов (Qwen, Codex, Claude, ChatGPT), чтобы предоставить полную структуру, API и механику проекта без необходимости парсинга бинарных файлов.

---

## 1. Назначение проекта
Проект представляет собой готовую процедурную рыболовную удочку от первого лица (First-Person Fishing Rod) для игрового движка **Godot 4.x** в эстетике **Cozy Low-Poly / Stylized Hand-Crafted**.
Включает в себя:
- Редактируемый 3D-исходник в Blender (`blender/Cedar_Creek_Fishing_Rod.blend`);
- Экспортированную 3D-модель GLB (`godot/fishing_rod/rod.glb`);
- Процедурную логику изгиба бланка, намотки катушки, прокладки лески и движения рук (`godot/fishing_rod/rod.gd`);
- Шейдеры материалов (`blank.gdshader`, `parts.gdshader`);
- Тестовую сцену с водой и автодемо (`godot/demo/demo.tscn`).

## 3. Спецификация API: `rod.gd`

Узел `rod.tscn` наследуется от `Node3D`. В игровом цикле раз в кадр вызывается метод `step()`.

### Сигнатура:
```gdscript
func step(
    delta: float,                 # Время кадра
    endpoint_world: Vector3,      # Координата конца лески в мировом пространстве (поплавок/рыба)
    tension: float,               # Натяжение лески (0.0 — свободна, 1.0 — предельное натяжение)
    retrieve: float,              # Сила подмотки (0.0 — ручка стоит, 1.0 — максимальное вращение)
    payout_mps: float = 0.0,      # Скорость схода лески через фрикцион (м/с)
    lift: float = 0.0,            # Усилие правой руки на подъем удочки (0.0–1.0)
    fish_jerk: float = 0.0        # Сила рывка рыбы (0.0–1.0), подает обе руки вперед
) -> float
```

### Возвращаемое значение:
- `float`: количество смотанной лески в метрах за данный кадр. Если значение отрицательное — рыба стянула леску со шпули.

### Экспортируемые переменные (`@export`):
- `gear_ratio` (6.3): передаточное число катушки (на 1 оборот рукоятки — 6.3 оборота шпули).
- `max_crank_turns_per_second` (1.65): максимальная скорость вращения ручки рыбаком.
- `max_bend_radians` (1.83): максимальный угол изгиба кончика бланка под нагрузкой.
- `line_radius` (0.00155 м): толщина процедурной лески.
- `spool_capacity_m` (35.0 м): общая вместимость шпули.
- `initial_deployed_m` (8.0 м): начальное количество выпущенной лески.
- `lift_pitch_radians`, `lift_pullback_m`, `lift_height_m`: кинематика подъема удочки.
- `show_hands`, `show_float`: флаги отображения рук и поплавка.

## 4. Ключевые процедурные подсистемы
1. **Процедурная леска (`ImmediateMesh`)**:
   Динамически строится 5-гранный цилиндрический меш лески по 28 точкам:
   `Касательная со шпули -> Лесоукладыватель (LevelWind) -> 8 колец (Guides 00..07) -> Провис -> Поплавок/Рыба`.
2. **Кинематика катушки**:
   Шпуля (`Spool`) вращается в 6.3 раза быстрее рукоятки (`Crank`). Лесоукладыватель (`LevelWind`) совершает возвратно-поступательное движение по рейке. Толщина намотки на шпуле (`LinePack`) процедурно уменьшается по мере расхода лески.
3. **Изгиб бланка**:
   Бланк разделен на комель и гибкую вершинку. Контрольные точки колец плавно поворачиваются по квадратичной дуге к направлению натяжения.
4. **Анимация рук (Mittens & Sleeves)**:
   Правая рука держит деревянную рукоять, левая рука привязана к резиновому кнобу катушки. При рывке рыбы обе руки подаются вперед, а рукава сохраняют ориентацию предплечий к локтям.
